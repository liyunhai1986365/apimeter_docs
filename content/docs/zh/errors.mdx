错误响应使用统一结构。

```json
{
  "error": {
    "code": "rate_limit_exceeded",
    "message": "Too many requests. Retry after 20 seconds.",
    "request_id": "req_123"
  }
}
```

## 常见状态码

| 状态码 | 含义 | 建议处理 |
| --- | --- | --- |
| `400` | 请求体或参数无效 | 修改请求后再试 |
| `401` | API Key 缺失或无效 | 检查 Bearer Token |
| `429` | 触发限流 | 使用退避策略重试 |
| `500` | 服务异常 | 对幂等请求进行重试 |

## 重试策略

对 `429`、`500`、`502`、`503` 使用指数退避。校验错误不要在不修改请求的情况下重试。
