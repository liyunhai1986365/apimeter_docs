## 集成指南

大多数应用只需要配置以下信息即可连接 ModelSell：

1. **API 地址**：ModelSell 服务地址，通常以 `/v1` 结尾。
2. **API Key**：在 ModelSell 控制台生成的访问令牌。
3. **模型名称**：选择需要调用的模型 ID。

具体配置步骤请参考各应用的详细文档。

<Callout title="兼容性提示">
如果工具支持 OpenAI-compatible、Custom Endpoint 或 BYOK 模式，通常可以把 ModelSell 的 API 地址、API Key 和模型名称填入对应位置完成接入。
</Callout>
