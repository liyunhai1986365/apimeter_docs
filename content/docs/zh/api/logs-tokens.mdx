---
title: 日志与令牌
description: 请求日志、统计和 API 令牌管理接口。
icon: KeyRound
---

日志和令牌接口用于管理 API Key、查看请求记录和统计用量。管理员可查看全部日志，普通用户可查看个人日志；Token 相关接口通常要求用户登录或管理上下文。
