这一组接口用于检索增强、排序和安全检查。Embeddings 负责把文本转换为向量；Rerank 用于按查询重新排序候选文档；Moderations 用于内容安全审核。

## OpenAI

### Embeddings

将文本转换为向量。请求路径是 `POST /v1/embeddings`。
