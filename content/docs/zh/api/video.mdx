视频接口通常是异步任务模式：先创建任务，再通过任务 ID 查询状态；部分 OpenAI 兼容接口还提供内容下载和 remix。

## OpenAI / Sora 兼容

- [OpenAI 视频任务](/zh/docs/api/video/openai-videos)：创建任务与查询任务。
- [OpenAI 视频内容下载](/zh/docs/api/video/openai-video-content)：下载已生成的视频内容。
- [OpenAI 视频 Remix](/zh/docs/api/video/openai-video-remix)：基于已有视频创建 remix 任务。

## 通用视频

- [通用视频任务](/zh/docs/api/video/generic-video)：创建任务与查询任务。
