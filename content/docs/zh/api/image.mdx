图片接口按协议分为 OpenAI Images 和 Gemini 原生格式。OpenAI 格式适合迁移现有图像生成/编辑代码，Gemini 原生格式适合直接使用 `generateContent` 的多模态结构。

## OpenAI

- [OpenAI 图片生成](/zh/docs/api/image/openai-generations)：通过提示词创建图片。
- [OpenAI 图片编辑](/zh/docs/api/image/openai-edits)：上传原图和可选遮罩进行编辑。

## Gemini

- [Gemini 图像](/zh/docs/api/image/gemini-image)：Gemini 原生图像 generateContent。
