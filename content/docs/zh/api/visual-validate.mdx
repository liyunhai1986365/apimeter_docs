真人认证接口用于创建认证会话、查询认证结果、上传和管理人像素材。接口返回统一管理响应结构，具体业务数据在 `data` 字段中。

## 认证会话

### 创建会话

创建 BytePlus 真人认证会话，并返回可分发给终端用户的 H5 链接。请求路径是 `POST /api/resource-channel/byteplus/visual-validate/sessions`。

  title="真人认证 - 创建会话"
/>

### 查询会话

获取真人认证结果，并查询关联的 GroupId。请求路径是 `GET /api/resource-channel/byteplus/visual-validate/sessions/{session_id}`。
