仅 Cursor **Pro 及以上**订阅用户可配置自定义模型和自定义 Base URL，免费版会报错。

## 安装 Cursor

前往 [Cursor 官网](https://cursor.com/cn/download) 下载并安装。

## 配置 ModelSell

### 打开设置

在 Cursor 中点击设置图标（右上角齿轮） → **Cursor Settings** → **Models** 页面。

### 配置 API Key 和 Base URL

1. 启用 **OpenAI API Key** 并输入您的 ModelSell 令牌（API Key）。
2. 启用 **Override OpenAI Base URL** 并输入：
   ```text
   https://modelsell.com/v1
   ```

### 添加模型

在 **Add or search model** 输入框中输入需要使用的模型名称（例如 `gpt-4o`, `claude-3-5-sonnet` 等），单击 **Add Custom Model**。

### 开始使用

在聊天面板选择对应模型即可使用。

## 常见问题

**报错 `The model xxx does not work with your current plan or api key.`**

您当前使用的是 Cursor 免费版，免费版不支持自定义模型。请升级至 Cursor Pro 或以上。
