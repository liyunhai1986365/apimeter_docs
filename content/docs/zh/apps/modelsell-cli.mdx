ModelSell CLI 是一个本地命令行配置工具，可以把 ModelSell 的 API Key、API 地址和默认模型写入主流 Agent 工具的本地配置文件。置。

## 适用场景

- 已经有 ModelSell API Key，希望快速把常用 Agent 工具接入 ModelSell。
- 同一台电脑上同时使用 Claude Code、Codex、Gemini CLI 或 OpenClaw，不想逐个编辑配置文件。
- 需要在新电脑、服务器或团队环境里用脚本快速初始化 Agent 工具配置。
- 希望写入配置前自动保留旧配置备份，降低误改本地文件的风险。

![modelsell-cli](/assets/docs/apps/modelsell/modelsell-cli.png)

## 一键安装

macOS 和 Linux 使用以下命令安装：

```bash
curl -fsSL https://static.modelsell.com/modelsell-cli/install.sh | sh
```

Windows PowerShell 使用以下命令安装：

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://static.modelsell.com/modelsell-cli/install.ps1 | iex"
```

安装完成后，重新打开终端或 PowerShell，确认命令可用：

```bash
modelsell
```

<Callout title="安装位置">
macOS 和 Linux 默认安装到 `~/.local/bin/modelsell`。Windows 默认安装到 `%USERPROFILE%\.local\bin\modelsell.exe`。如果提示找不到 `modelsell` 命令，请确认安装目录已经加入 `PATH`，或重新打开终端。
</Callout>

## 交互式配置

直接运行：

```bash
modelsell
```

CLI 会显示交互式菜单，你可以选择配置全部工具，或只配置某一个目标。根据提示填入 ModelSell API Key、API 地址和模型名称后，工具会自动写入对应平台的配置文件。

支持的目标包括：

| 目标 | 说明 |
| --- | --- |
| `all` | 一次性配置 Claude Code、Codex、Gemini CLI 和 OpenClaw |
| `claude` | 配置 Claude Code |
| `codex` | 配置 Codex CLI |
| `gemini` | 配置 Gemini CLI |
| `openclaw` | 配置 OpenClaw |
