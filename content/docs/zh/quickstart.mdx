本指南展示从 API Key 到模型响应的最短路径。

## 1. 设置 API Key

运行示例前，先把密钥写入环境变量：

```bash
export MODELSELL_API_KEY="ms_live_your_key"
```

## 2. 调用模型

response = requests.post(

    json={
        "model": "modelsell-chat",
        "messages": [{"role": "user", "content": "Write a concise launch note."}],
    },
