ModelSell 文档把产品指南、可复制的代码示例和 OpenAPI 驱动的 API Reference 放在同一个文档系统里。

## 包含内容

- 基于 Fumadocs 和 MDX 的文档系统。
- 支持 curl、JavaScript、Python 的交互式代码示例。
- 由 `content/openapi/modelsell.yaml` 生成的 API Reference。
- 可在 [/zh/api-reference](/zh/api-reference) 中尝试请求的 API Playground。

## 推荐路径

1. 从 [快速开始](/zh/docs/quickstart) 开始。
2. 在 [认证](/zh/docs/authentication) 中配置 API Key。
3. 按需查看 [接入 Agent 工具](/zh/docs/apps)，把 ModelSell 配置到常用客户端。
4. 通过 [Chat Completions](/zh/docs/models/chat-completions) 发送模型请求。
5. 查看生成的 [API Reference](/zh/api-reference/ai-%E6%A8%A1%E5%9E%8B---%E8%81%8A%E5%A4%A9/createChatCompletion)。

<Callout title="本地优先">
示例使用 `https://modelsell.com` 作为占位 API 地址。后端上线后替换为真实 endpoint 即可。
</Callout>
