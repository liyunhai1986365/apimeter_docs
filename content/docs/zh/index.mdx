ModelSell 文档现在只保留两类入口：面向客户端和 Agent 的接入指南，以及由 OpenAPI 自动生成的 API Reference / Playground。

## 常用入口

<Cards>
  <Card title="接入 Agent 工具" href="/zh/docs/apps">
    Claude Code、Codex CLI、Gemini CLI、OpenClaw、Cursor、Cherry Studio 等客户端接入指南。
  </Card>

  <Card title="一键配置主流 Agent 平台" href="/zh/docs/apps/modelsell-cli">
    使用 ModelSell CLI 自动写入 API Key、Base URL 和默认模型，适合快速配置本地工具链。
  </Card>

  <Card title="API Reference / Playground" href="/zh/docs/api-reference">
    展开完整 OpenAPI 参数、响应结构和 Playground，按聊天、图片、视频、音频等分类直接调试接口请求。
  </Card>
</Cards>

## 按目标选择

| 目标 | 建议入口 |
| --- | --- |
| 把 ModelSell 接入某个 Agent 或客户端 | [接入 Agent 工具](/zh/docs/apps) |
| 批量配置 Claude Code、Codex、Gemini CLI、OpenClaw | [ModelSell CLI](/zh/docs/apps/modelsell-cli) |
| 查看聊天、图片、视频、音频、向量等能力接口 | [API Reference / Playground](/zh/docs/api-reference) |
| 查看完整字段并在线调试 | [API Reference / Playground](/zh/docs/api-reference) |

<Callout title="建议路径">
如果你正在第一次接入，优先从 Agent 工具或 ModelSell CLI 开始；如果你在写服务端代码，直接进入 API Reference / Playground。
</Callout>
