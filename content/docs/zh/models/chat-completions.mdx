## 请求结构

`messages` 数组应保持会话顺序。`system` 消息是可选的，适合用于设置模型行为。

## 响应结构

响应会返回 `choices`，每个 choice 包含一条 assistant `message`。

```json
{
  "id": "chatcmpl_123",
  "object": "chat.completion",
  "model": "modelsell-chat",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Fumadocs is a documentation framework for building fast MDX-powered docs with Next.js."
      },
      "finish_reason": "stop"
    }
  ]
}
```
