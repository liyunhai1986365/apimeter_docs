## 通用规则

除特殊说明外，请求头使用：

```http
Content-Type: application/json
Authorization: Bearer {apikey}
```

常规 `/kling/v1/videos/*` 异步任务一般包含三个接口：

| 请求方式 | 用途 |
| --- | --- |
| `POST /kling/v1/videos/{capability}` | 创建任务 |
| `GET /kling/v1/videos/{capability}/{id}` | 查询单个任务 |
| `GET /kling/v1/videos/{capability}?pageNum=1&pageSize=30` | 分页查询任务列表 |

Kling 3.0 Turbo 是例外，它使用 `/kling/text-to-video/kling-3.0-turbo`、`/kling/image-to-video/kling-3.0-turbo` 创建任务，并使用 `/kling/tasks` 查询任务。
