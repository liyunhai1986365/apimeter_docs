本示例兼容字节／火山方舟官方视频任务格式，使用平台 API Key。先配置 `APIMETER_BASE_URL`（平台 API 根地址，不含 `/api/v3`）和 `APIMETER_API_KEY`，将下方代码保存为 `seedance_poll.py`。

轮询默认最多 30 分钟、间隔 10 秒，使用单调时钟计算耗时。临时连接错误、429 和 5xx 会在间隔后重试查询；401、403、404 等立即报错。创建任务不自动重试，避免网络超时导致重复提交。

```python
import os
import sys
import time
from pathlib import Path

import requests

BASE_URL = os.environ["APIMETER_BASE_URL"].rstrip("/")
API_KEY = os.environ["APIMETER_API_KEY"]
MODEL = "doubao-seedance-2-0-260128"
HEADERS = {"Authorization": f"Bearer {API_KEY}"}


def create_task(prompt: str) -> str:
    # Do not blindly retry task creation after a network timeout.
    response = requests.post(
        f"{BASE_URL}/api/v3/contents/generations/tasks",
        headers=HEADERS,
        json={
            "model": MODEL,
            "content": [{"type": "text", "text": prompt}],
            "resolution": "720p",
            "ratio": "16:9",
            "duration": 5,
            "generate_audio": True,
            "watermark": False,
        },
        timeout=(10, 180),
    )
    response.raise_for_status()
    task_id = response.json().get("id")
    if not task_id:
        raise RuntimeError("Create response is missing id")
    return task_id


def wait_for_result(task_id: str, max_wait: int = 1800, interval: int = 10) -> str:
    if max_wait <= 0 or interval <= 0:
        raise ValueError("max_wait and interval must be positive")
    deadline = time.monotonic() + max_wait
    while time.monotonic() < deadline:
        # Bound each request by the remaining polling budget.
        remaining = deadline - time.monotonic()
        if remaining <= 0:
            break
        try:
            response = requests.get(
                f"{BASE_URL}/api/v3/contents/generations/tasks/{task_id}",
                headers=HEADERS,
                timeout=min(60, remaining),
            )
        except (requests.Timeout, requests.ConnectionError):
            response = None

        if response is not None:
            if response.status_code != 429 and response.status_code < 500:
                response.raise_for_status()
                data = response.json()
                status = data.get("status")
                print(f"task_id={task_id} status={status}", flush=True)
                if status == "succeeded":
                    url = (data.get("content") or {}).get("video_url")
                    if not url:
                        raise RuntimeError("Successful task is missing content.video_url")
                    return url
                if status in {"failed", "expired", "cancelled", "canceled"}:
                    raise RuntimeError(f"Task ended: {status}; error={data.get('error')}")
                if status not in {"queued", "running"}:
                    raise RuntimeError(f"Unexpected task status: {status}")

        remaining = deadline - time.monotonic()
        if remaining > 0:
            time.sleep(min(interval, remaining))

    raise TimeoutError(f"Polling timed out; resume with task ID: {task_id}")


def download_video(video_url: str, save_path: str) -> None:
    target = Path(save_path)
    partial = target.with_name(target.name + ".part")
    # The signed media URL does not need the platform Authorization header.
    with requests.get(video_url, stream=True, timeout=(10, 120)) as response:
        response.raise_for_status()
        with partial.open("wb") as output:
            for chunk in response.iter_content(chunk_size=1024 * 1024):
                if chunk:
                    output.write(chunk)
    partial.replace(target)


if __name__ == "__main__":
    # Pass an existing task ID to resume instead of creating another task.
    task_id = sys.argv[1] if len(sys.argv) > 1 else create_task(
        "A golden dog runs beneath cherry blossoms; the camera slowly rises"
    )
    print(f"task_id={task_id}", flush=True)
    video_url = wait_for_result(task_id)
    download_video(video_url, "seedance-output.mp4")
```

## 运行与恢复查询

```bash
python seedance_poll.py
python seedance_poll.py "<已有的任务ID>"
```

第二条命令只查询已有任务，不重新创建。建议创建后立即持久化输出的任务 ID。

`failed`、`expired`、`cancelled`、`canceled` 状态会终止轮询，后两者均表示已取消；错误中保留任务状态和服务端错误。成功响应缺少视频 URL 时也会明确报错。下载先写入 `.part`，完成后替换目标文件；下载失败可重新查询原任务获取地址后重试。

客户端超时只表示停止等待，不会取消任务。官方任务记录仅保留最近 7 天，视频下载 URL 有效期为 24 小时，应及时转存。示例的总预算控制轮询调度与单次请求超时，网络底层行为可能使实际墙钟耗时略有超出。

本例读取[视频任务查询接口](./overview)的 `status` 与 `content.video_url`。素材库查询则使用 POST Action 请求，读取 `Result.Status`，见[素材库](./assets)。
