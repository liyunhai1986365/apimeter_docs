Seedance 视频生成与素材库使用统一 API，**兼容字节／火山方舟官方格式**。所有请求使用同一 API 根地址和 API Key；视频采用 `content[]`，素材库采用 `Action` 请求和 `ResponseMetadata + Result` 响应。

## 接口地址与鉴权

| 操作 | 方法与地址 | 结果读取位置 |
| --- | --- | --- |
| 创建视频任务 | `POST /api/v3/contents/generations/tasks` | `id` |
| 查询视频任务 | `GET /api/v3/contents/generations/tasks/{task_id}` | `status`、`content.video_url` |
| 素材与素材组管理 | `POST /?Action=<操作名>&Version=2024-01-01` | `ResponseMetadata`、`Result` |

所有示例使用 `Authorization: Bearer $APIMETER_API_KEY`。`APIMETER_BASE_URL` 为平台 API 根地址，不含 `/api/v3`。

素材库与视频任务使用相同的 Bearer 鉴权。素材创建、管理与引用流程见[素材库（官方格式）](./assets)。

## 模型与输出规格

`model` 填写账户可用的 Seedance 模型 ID 或模型别名。不同型号使用相同的任务接口，参数按所选模型的规格填写。

本节基础示例使用 Seedance 2.0：

| 模型 | 示例模型 ID | 2.0 官方输出分辨率 |
| --- | --- | --- |
| Seedance 2.0 | `doubao-seedance-2-0-260128` | `480p`、`720p`、`1080p`、`4k` |
| Seedance 2.0 Fast | `doubao-seedance-2-0-fast-260128` | `480p`、`720p` |

标准版 4k 视频使用 10bit H.265/HEVC。Fast 不支持 `1080p` 或 `4k`。其他型号请按对应模型规格设置分辨率、时长和功能参数。

## 创建与查询视频任务

```bash
curl -X POST "$APIMETER_BASE_URL/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $APIMETER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "content": [{"type": "text", "text": "一只金色柴犬在樱花树下奔跑，镜头缓缓上升"}],
    "resolution": "720p",
    "ratio": "16:9",
    "duration": 5,
    "generate_audio": true,
    "watermark": false
  }'
```

创建响应至少包含任务 ID。原样保存，不依赖固定前缀；此时不要求已有状态或视频地址：

```json
{"id": "<TASK_ID>"}
```

```bash
curl "$APIMETER_BASE_URL/api/v3/contents/generations/tasks/$TASK_ID" \
  -H "Authorization: Bearer $APIMETER_API_KEY"
```

成功查询的结构示例：

```json
{
  "id": "<TASK_ID>",
  "status": "succeeded",
  "model": "doubao-seedance-2-0-260128",
  "content": {"video_url": "https://example.com/result.mp4"},
  "usage": {"completion_tokens": 100858, "total_tokens": 100858},
  "error": null
}
```

## 请求参数

参数放在 JSON 顶层，媒体内容放在 `content[]`。`0`、`false`、`-1` 按参数含义处理；省略可选参数时使用模型默认值。

| 字段 | 说明 |
| --- | --- |
| `model`、`content` | 模型与内容数组；基础媒体类型为 `text`、`image_url`、`video_url`、`audio_url` |
| `resolution`、`ratio` | 分辨率与比例；2.0 默认 `720p`、`adaptive` |
| `duration` | 2.0 使用整数 4–15 秒；支持自动时长的模型可传 `-1` |
| `generate_audio`、`watermark` | 2.0 默认分别为 `true`、`false`，示例显式传入 |
| `return_last_frame` | 请求返回末帧；成功后读取返回的 `content.last_frame_url` |
| `callback_url` | 任务回调地址，使用可公网访问的 URL |
| `execution_expires_after` | 服务端任务过期时间，单位秒，官方范围 3600–259200 |
| `priority`、`safety_identifier`、`tools` | 优先级、安全标识和工具配置；`web_search` 是否可用由模型决定 |
| `seed`、`frames`、`camera_fixed`、`draft`、`service_tier` | 随机种子、帧数、固定镜头、样片模式和推理等级，按所选模型规格使用 |
| `output_format`、`omni_reference_task_type` | 供支持这些能力的型号使用；2.5 可用任务类型为 `auto`、`reference`、`edit`、`extend` |

`omni_reference_task_type=edit` 必须搭配 `duration=-1`、`ratio=adaptive` 和 `reference_video`；`extend` 也必须提供 `ratio=adaptive` 和参考视频。2.0 示例通过提示词表达编辑或延长意图，不使用这些 2.5 参数。

Seedance 2.0 不支持 `draft` 或 `service_tier: "flex"`；2.0 请求也请省略 `seed`、`frames`、`camera_fixed`。完整字段见本节视频生成接口参考。

## 输入与任务状态

2.0 的首帧、首尾帧和全模态参考是互斥模式。全模态最多 9 张图片、3 段视频、3 段音频，音频必须搭配图片或视频。角色和 JSON 示例见[生成模式示例](./modes)，素材来源及规格见[素材库](./assets)。

| `status` | 客户端处理 |
| --- | --- |
| `queued`、`running` | 继续轮询 |
| `succeeded` | 读取 `content.video_url`，如有需要同时保存末帧与用量 |
| `failed`、`expired`、`cancelled`、`canceled` | 停止轮询，检查 `error`；后两者均表示已取消 |

查询响应包含任务状态、结果链接和 `usage` 用量信息，成功时 `error` 可以为 `null`。

请在任务创建后 7 天内查询结果，并在生成成功后及时下载；视频 URL 通常在 24 小时后失效。客户端停止轮询不会取消服务端任务。完整创建、恢复查询与下载示例见[Python 轮询与下载](./python-polling)。
