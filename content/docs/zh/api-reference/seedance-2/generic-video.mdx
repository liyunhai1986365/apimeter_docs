---
title: 通用视频格式调用
description: 平台 /v1/video/generations 与 Seedance 2.0 原生格式的字段映射及边界。
---

`/v1/video/generations` 是平台封装接口，由平台转换为 Seedance 2.0 的 `content[]` 请求，不是火山方舟官方接口。需要首帧、首尾帧或精确多素材角色时，优先使用[原生格式](./modes)。

## 接口与映射

| 操作 | 地址 |
| --- | --- |
| 创建 | `POST /v1/video/generations` |
| 查询 | `GET /v1/video/generations/{task_id}` |

不要混用 `/v1/videos` 的字段或查询接口。

| 平台字段 | 原生字段 / 含义 |
| --- | --- |
| `prompt` | `content[]` 中的 `text` |
| `image` 或 `images[]` | `image_url`，角色为 `reference_image`；不等同于首帧或首尾帧 |
| `metadata.video_url` | `video_url`，角色为 `reference_video` |
| `metadata.audio_url` | `audio_url`，角色为 `reference_audio`；必须搭配图片或视频 |
| `size` | `resolution`；Fast 仅 `480p` / `720p`，标准版另有 `1080p`；官方标准版 `4k` 需确认平台渠道支持 |
| `duration` 或 `seconds` | 输出秒数，示例采用整数 4–15；不要同时传两个时长字段 |
| `metadata.ratio` | `ratio`，包括 `21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`adaptive` |
| `metadata.generate_audio` | `generate_audio` |
| `metadata.watermark` | `watermark` |

官方原生 `duration: -1` 表示智能选择时长，平台通用接口是否保留该取值需另行确认。本页不把它作为已确认的通用参数。多段参考视频/音频、回调、尾帧返回及工具调用也不要自行扩展为未经定义的 `metadata` 字段。

## 文生视频

```bash
curl -X POST "$MODELSELL_BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer $MODELSELL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "一只金色柴犬在樱花树下奔跑，镜头缓缓上升",
    "duration": 5,
    "size": "720p",
    "metadata": {"ratio": "16:9", "generate_audio": true, "watermark": false}
  }'
```

## 全模态参考

以下 JSON 可用作创建任务的请求体。只需要图片参考时去掉视频和音频；音频不可单独使用。提示词用同类素材顺序指代输入。

```json
{
  "model": "doubao-seedance-2-0-fast-260128",
  "prompt": "参考图片1的色彩与视频1的运镜，使用音频1作为背景音乐",
  "image": "https://example.com/reference-image.jpg",
  "duration": 5,
  "size": "720p",
  "metadata": {
    "ratio": "16:9",
    "video_url": "https://example.com/reference-video.mp4",
    "audio_url": "https://example.com/reference-audio.mp3",
    "generate_audio": true,
    "watermark": false
  }
}
```

素材可按本平台约定用同渠道下已为 `Active` 的 `asset://<asset_id>` 替换对应 URL，见[素材管理](./assets)。官方支持的图片/音频 Base64 规则不能直接视为平台通用格式的完整支持承诺，大素材优先使用 URL。

## 查询与结果

保存创建响应中的 `id` 或 `task_id`，原样用于同一接口族查询：

```bash
curl "$MODELSELL_BASE_URL/v1/video/generations/$TASK_ID" \
  -H "Authorization: Bearer $MODELSELL_API_KEY"
```

平台通用成功响应示例：

```json
{
  "id": "<TASK_ID>",
  "task_id": "<TASK_ID>",
  "object": "video.generation",
  "status": "succeeded",
  "model": "doubao-seedance-2-0-260128",
  "metadata": {"url": "https://example.com/result.mp4"}
}
```

此处结果位置是平台示例的 `metadata.url`，原生接口则为 `content.video_url`，不要混读。轮询应设置间隔、总超时并处理失败终态；成功后立即下载或转存。官方输出地址有效期为 24 小时，平台响应与有效期以渠道为准。

更多角色与生成模式见[生成模式示例](./modes)，官方规则见[创建视频生成任务](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)。
