本页说明通过 `/v1/video/generations` 调用 Seedance 2.0 的参数和结果读取方式。Seedance 官方格式接入见[统一 API 概览](./overview)。

## 接口与映射

| 操作 | 地址 |
| --- | --- |
| 创建 | `POST /v1/video/generations` |
| 查询 | `GET /v1/video/generations/{task_id}` |

不要混用 `/v1/videos` 的字段或查询接口。

| 平台字段 | 原生字段 / 含义 |
| --- | --- |
| `prompt` | `content[]` 中的 `text` |
| `image` 或 `images[]` | `image_url`，角色为 `reference_image`；不等同于首帧或首尾帧 |
| `metadata.video_url` | `video_url`，角色为 `reference_video` |
| `metadata.audio_url` | `audio_url`，角色为 `reference_audio`；必须搭配图片或视频 |
| `size` | `resolution`；Fast 使用 `480p` / `720p`，标准版还支持 `1080p` / `4k` |
| `duration` 或 `seconds` | 输出秒数，示例采用整数 4–15；不要同时传两个时长字段 |
| `metadata.ratio` | `ratio`，包括 `21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`adaptive` |
| `metadata.generate_audio` | `generate_audio` |
| `metadata.watermark` | `watermark` |

支持自动时长的模型可传 `duration: -1`；`metadata.video_url`、`metadata.audio_url` 可为 URL 数组。`metadata.return_last_frame`、`metadata.callback_url`、`metadata.tools` 等选项按所选模型规格填写。

## 文生视频

```bash
curl -X POST "$APIMETER_BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer $APIMETER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "一只金色柴犬在樱花树下奔跑，镜头缓缓上升",
    "duration": 5,
    "size": "720p",
    "metadata": {"ratio": "16:9", "generate_audio": true, "watermark": false}
  }'
```

## 全模态参考

以下 JSON 可用作创建任务的请求体。只需要图片参考时去掉视频和音频；音频不可单独使用。提示词用同类素材顺序指代输入。

```json
{
  "model": "doubao-seedance-2-0-fast-260128",
  "prompt": "参考图片1的色彩与视频1的运镜，使用音频1作为背景音乐",
  "image": "https://example.com/reference-image.jpg",
  "duration": 5,
  "size": "720p",
  "metadata": {
    "ratio": "16:9",
    "video_url": "https://example.com/reference-video.mp4",
    "audio_url": "https://example.com/reference-audio.mp3",
    "generate_audio": true,
    "watermark": false
  }
}
```

素材可使用当前账户有权访问且状态为 `Active` 的 `asset://<asset_id>` 替换对应 URL，见[素材库](./assets)。本页示例使用公网 URL 提交参考媒体。

## 查询与结果

保存创建响应中的 `id` 或 `task_id`，原样用于同一接口族查询：

```bash
curl "$APIMETER_BASE_URL/v1/video/generations/$TASK_ID" \
  -H "Authorization: Bearer $APIMETER_API_KEY"
```

平台通用成功响应示例：

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "<TASK_ID>",
    "status": "SUCCESS",
    "result_url": "https://example.com/result.mp4"
  }
}
```

通用查询读取 `data.status` 与 `data.result_url`：`NOT_START`、`SUBMITTED`、`QUEUED`、`IN_PROGRESS` 继续等待，`SUCCESS` 成功，`FAILURE` 失败并检查 `data.fail_reason`。创建响应与查询响应结构不同。轮询应设置间隔、总超时并处理失败终态；成功后立即下载或转存，视频 URL 通常在 24 小时后失效。

更多角色与生成模式见[生成模式示例](./modes)，官方规则见[创建视频生成任务](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)。
