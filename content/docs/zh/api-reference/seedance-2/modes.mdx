以下请求体均提交到 `POST /api/v3/contents/generations/tasks`。所有 URL 为占位示例，请替换为可访问的素材 URL 或同渠道下已为 `Active` 的 `asset://<asset_id>`。

## 模式与角色规则

| 模式 | 图片角色 | 组合要求 |
| --- | --- | --- |
| 首帧 | `first_frame`（官方也允许单图不填 role） | 1 张首帧图片 |
| 首尾帧 | `first_frame` + `last_frame` | 2 张图片，明确指定角色 |
| 全模态参考 | `reference_image` | 可组合图片、`reference_video` 视频、`reference_audio` 音频 |

这三种模式互斥，不要把 `first_frame` / `last_frame` 与全模态参考角色混用。若需要参考多模态又希望指定首尾画面，可在提示词中描述“图片1作为首帧”，但不等同于首尾帧模式的严格约束。

全模态参考最多 9 张图片、3 段视频、3 段音频；视频总时长不超过 15 秒，音频总时长不超过 15 秒。不支持仅音频或文本加音频，音频必须搭配参考图片或视频。

提示词按同类素材顺序使用“图片1”“视频1”“音频1”，从 1 编号；不要在提示词中填写 Asset ID。真人人像需按授权流程使用，不能直接把未经授权处理的人脸 URL 作为普通参考图。详见[素材管理](./assets)。

## 文生视频

```json
{
  "model": "doubao-seedance-2-0-260128",
  "content": [
    {
      "type": "text",
      "text": "一只柴犬在樱花树下奔跑"
    }
  ],
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5,
  "generate_audio": true,
  "watermark": false
}
```

## 延长视频

```json
{
  "model": "doubao-seedance-2-0-260128",
  "content": [
    {
      "type": "text",
      "text": "向后延长视频1，镜头继续穿过森林到达湖面"
    },
    {
      "type": "video_url",
      "video_url": {
        "url": "https://example.com/reference-video.mp4"
      },
      "role": "reference_video"
    }
  ],
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5,
  "generate_audio": true,
  "watermark": false
}
```

编辑和延长沿用参考视频角色，通过提示词表达意图，不使用 Seedance 2.5 专用的 `omni_reference_task_type`。延长可输入最多 3 段视频并描述衔接，输出仍受 4–15 秒限制，不保证默认包含全部原片。
