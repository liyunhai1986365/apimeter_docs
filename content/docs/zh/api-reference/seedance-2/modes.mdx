---
title: 生成模式示例
description: Seedance 2.0 七种官方 content 组合模式示例。
---

Seedance 2.0 的官方格式通过 `content[]` 表达文本、图片、视频和音频输入。图片素材的 `role` 使用 `reference_image`，视频素材使用 `reference_video`，音频素材使用 `reference_audio`。

## 文生视频

```json
{
  "model": "doubao-seedance-2-0-260128",
  "content": [
    {
      "type": "text",
      "text": "一只金色柴犬在樱花树下奔跑，镜头缓缓上升"
    }
  ],
  "resolution": "480p",
  "ratio": "16:9",
  "duration": 5,
  "watermark": false
}
```

## 图生视频

```json
{
  "model": "doubao-seedance-2-0-fast-260128",
  "content": [
    {
      "type": "text",
      "text": "让画面中的人物缓缓转身微笑"
    },
    {
      "type": "image_url",
      "image_url": {
        "url": "https://example.com/photo.jpg"
      },
      "role": "reference_image"
    }
  ],
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5,
  "watermark": false
}
```

## 视频生视频

```json
{
  "model": "doubao-seedance-2-0-260128",
  "content": [
    {
      "type": "text",
      "text": "让视频中的人物变成卡通风格"
    },
    {
      "type": "video_url",
      "video_url": {
        "url": "https://example.com/reference-video.mp4"
      },
      "role": "reference_video"
    }
  ],
  "resolution": "480p",
  "ratio": "16:9",
  "duration": 5,
  "generate_audio": true,
  "watermark": false
}
```
