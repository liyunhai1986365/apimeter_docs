Seedance 素材库统一使用以下入口，**兼容字节／火山方舟官方格式**：

```text
POST /?Action=<操作名>&Version=2024-01-01
```

所有操作均为 **POST**，包括查询、列表和删除。JSON 字段区分大小写，使用 `GroupId`、`URL`、`AssetType`、`Name`、`ProjectName`。成功响应读取 `Result`，请求错误读取 `ResponseMetadata.Error`。

## 鉴权

请求发送到 `APIMETER_BASE_URL`，使用 `Authorization: Bearer $APIMETER_API_KEY`，与视频任务使用相同的 API 根地址和 API Key。

## 创建素材组

```bash
curl -X POST "$APIMETER_BASE_URL/?Action=CreateAssetGroup&Version=2024-01-01" \
  -H "Authorization: Bearer $APIMETER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"Name":"视频参考素材","Description":"虚拟角色参考","GroupType":"AIGC"}'
```

保存 `Result.Id` 作为后续的 `GroupId`：

```json
{
  "ResponseMetadata": {"RequestId":"request-example","Action":"CreateAssetGroup","Version":"2024-01-01"},
  "Result": {"Id":"group-example"}
}
```

## 创建素材

```bash
curl -X POST "$APIMETER_BASE_URL/?Action=CreateAsset&Version=2024-01-01" \
  -H "Authorization: Bearer $APIMETER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "GroupId":"group-example",
    "URL":"https://example.com/reference.png",
    "AssetType":"Image",
    "Name":"虚拟角色参考图"
  }'
```

`URL` 使用处理期间可访问的公网 URL，不使用 Base64。`AssetType` 可为 `Image`、`Video`、`Audio`，分别表示图片、视频和音频。

保存素材的 `Result.Id`。创建成功仅表示已受理，不能假定立即可用；`Status` 等附加字段以实际返回为准：

```json
{
  "ResponseMetadata": {"RequestId":"request-example","Action":"CreateAsset","Version":"2024-01-01"},
  "Result": {"Id":"asset-example"}
}
```

## 查询素材状态

```bash
curl -X POST "$APIMETER_BASE_URL/?Action=GetAsset&Version=2024-01-01" \
  -H "Authorization: Bearer $APIMETER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"Id":"asset-example"}'
```

```json
{
  "ResponseMetadata": {"RequestId":"request-example","Action":"GetAsset","Version":"2024-01-01"},
  "Result": {
    "Id":"asset-example",
    "GroupId":"group-example",
    "AssetType":"Image",
    "Name":"虚拟角色参考图",
    "Status":"Active",
    "URL":"https://example.com/reference.png"
  }
}
```

| `Result.Status` | 处理方式 |
| --- | --- |
| `Processing` | 继续轮询，设置间隔和总超时 |
| `Active` | 可以引用素材生成视频 |
| `Failed` | 停止轮询，检查 `Result.Error.Code`、`Result.Error.Message` |
| `Expired` 等其他状态 | 确认素材是否仍可用，不当作 `Active` |

HTTP 200/202 不代表素材已可用。查询返回 `Status=Failed` 可以是一次成功的查询；这与请求本身失败不同。官方素材访问 URL 通常有时效性，长期引用应保存素材 ID。

## 全部操作与请求体

以下 JSON 为各操作的典型请求体；所有请求都可按需携带 `ProjectName`。查询参数 `Action` 必须与所选请求体对应。

| Action | 用途 | 请求体示例 |
| --- | --- | --- |
| `CreateAssetGroup` | 创建素材组 | `{"Name":"参考组","Description":"","GroupType":"AIGC"}` |
| `GetAssetGroup` | 查询素材组 | `{"Id":"group-example"}` |
| `ListAssetGroups` | 素材组列表 | `{"Filter":{"GroupType":"AIGC"},"MaxResults":20}` |
| `UpdateAssetGroup` | 更新组名或描述 | `{"Id":"group-example","Name":"新组名","Description":"新描述"}` |
| `DeleteAssetGroup` | 删除素材组 | `{"Id":"group-example"}` |
| `CreateAsset` | 创建素材 | `{"GroupId":"group-example","URL":"https://example.com/reference.png","AssetType":"Image","Name":"参考图"}` |
| `GetAsset` | 查询素材 | `{"Id":"asset-example"}` |
| `ListAssets` | 素材列表 | `{"Filter":{"GroupType":"AIGC","GroupIds":["group-example"]},"MaxResults":20}` |
| `UpdateAsset` | 更新素材名称 | `{"Id":"asset-example","Name":"新素材名"}` |
| `DeleteAsset` | 删除素材 | `{"Id":"asset-example"}` |
| `CreateVisualValidateSession` | 创建真人认证会话 | `{"CallbackURL":"https://example.com/callback"}` |
| `GetVisualValidateResult` | 获取真人认证结果 | `{"BytedToken":"<认证会话凭证>"}` |

真人认证会话返回 `Result.H5Link`、`Result.BytedToken`。由用户打开 `H5Link` 完成认证，再使用 `BytedToken` 查询结果并保存返回的素材组信息。

列表读取 `Result.Items` 和返回的分页信息。`MaxResults/NextToken` 与 `PageNumber/PageSize` 两种分页不能混用；每页最多 100 条。下一页原样传入上一次响应的 `Result.NextToken`。列表只包含当前用户有权访问的素材。

更新、删除的 JSON 成功响应为 `ResponseMetadata + Result`，删除的 `Result` 为 `{}`；HTTP 204 表示操作成功且无响应体。删除素材组可能影响组内素材，调用前确认目标 ID。

## 错误处理

```json
{
  "ResponseMetadata": {
    "RequestId":"request-example",
    "Action":"GetAsset",
    "Version":"2024-01-01",
    "Error":{"Code":"asset_not_found","Message":"asset not found"}
  }
}
```

同时检查 HTTP 状态和 `ResponseMetadata.Error`，HTTP 200 也可能包含业务错误。根据 `Error.Code` 和 `Error.Message` 检查参数、资源 ID 或访问权限。遇到 429/503 时，按返回的 `Retry-After` 等待后重试查询。

创建请求超时或响应异常后不要盲目重复创建，应保存请求 ID 排查。查询失败或轮询超时保留原素材 ID，以便恢复。

## 使用素材生成视频

`asset://` 后拼接素材的 `Result.Id`，不要拼接 `GroupId`。素材须为 `Active`，且当前账户拥有该素材及所属项目的访问权限：

```json
{
  "model":"doubao-seedance-2-0-260128",
  "content":[
    {"type":"text","text":"让图片1中的虚拟角色在花园散步"},
    {"type":"image_url","image_url":{"url":"asset://asset-example"},"role":"reference_image"}
  ],
  "resolution":"720p",
  "ratio":"16:9",
  "duration":5,
  "generate_audio":true,
  "watermark":false
}
```

提交到 `POST /api/v3/contents/generations/tasks`。视频、音频素材分别使用 `video_url.url`、`audio_url.url`；见[生成模式示例](./modes)。

## 视频任务直接输入规范

以下是 Seedance 2.0 视频任务 `content[]` 的输入要求。素材入库的图片要求见表后说明。

| 类型 | 格式与来源 | Seedance 2.0 限制 |
| --- | --- | --- |
| 图片 | jpeg、png、webp、bmp、tiff、gif、heic、heif；公网 URL、Data URL 或可用资产 URI | 单张小于 30 MB；宽高比 [0.4, 2.5]；宽高各在 [300, 6000] px；全模态参考最多 9 张 |
| 视频 | mp4、mov；公网 URL 或可用资产 URI；不支持 Base64 | 单个 2–15 秒；最多 3 段且总时长不超过 15 秒；单个不超过 200 MB；24–60 FPS |
| 音频 | wav、mp3；公网 URL、Data URL 或可用资产 URI | 单个 2–15 秒；最多 3 段且总时长不超过 15 秒；单个不超过 15 MB；必须搭配图片或视频 |

视频宽高比为 [0.4, 2.5]，宽高各在 [300, 6000] px；宽×高应在 [407696, 8295044] 内。官方参考视频规格覆盖 480p、720p、1080p、4k，不能只按“480p 或 720p”判断。MP4/MOV 支持 H.264/AVC 与 H.265/HEVC，具体音轨编码见官方 API。

视频任务请求体不超过 64 MB，大文件使用 URL。私域虚拟人像入库的图片格式为 jpeg、png、webp、tiff、gif、heic/heif，宽高比 (0.4, 2.5)、宽高 (300, 6000) px，单张小于 30 MB。
