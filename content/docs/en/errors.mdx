Errors use a consistent response envelope.

```json
{
  "error": {
    "code": "rate_limit_exceeded",
    "message": "Too many requests. Retry after 20 seconds.",
    "request_id": "req_123"
  }
}
```

## Common status codes

| Status | Meaning | Recommended action |
| --- | --- | --- |
| `400` | Invalid request body or parameters | Fix the request before retrying |
| `401` | Missing or invalid API key | Check the bearer token |
| `429` | Rate limit exceeded | Retry with backoff |
| `500` | Service error | Retry idempotent requests |

## Retry policy

Use exponential backoff for `429`, `500`, `502`, and `503` responses. Do not retry validation errors without changing the request.
