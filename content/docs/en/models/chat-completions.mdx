Chat completions accept a model name and an ordered list of messages.

## Request shape

The `messages` array should preserve the conversation order. A `system` message is optional but useful for setting behavior.

## Response shape

The response returns `choices`, each containing an assistant `message`.

```json
{
  "id": "chatcmpl_123",
  "object": "chat.completion",
  "model": "modelsell-chat",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Fumadocs is a documentation framework for building fast MDX-powered docs with Next.js."
      },
      "finish_reason": "stop"
    }
  ]
}
```
