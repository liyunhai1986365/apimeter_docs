ModelSell Docs combines product guidance, copy-ready code examples, and an OpenAPI-powered API reference.

## What is included

- A Fumadocs documentation system backed by MDX.
- Interactive code examples for curl, JavaScript, and Python.
- An API reference generated from `content/openapi/modelsell.yaml`.
- A playground route at [/docs/api-reference](/docs/api-reference) for trying requests.

## First path

1. Start with [Quickstart](/docs/quickstart).
2. Add an API key from [Authentication](/docs/authentication).
3. Send a chat request from [Chat Completions](/docs/models/chat-completions).
4. Inspect the generated [API Reference](/docs/api-reference/ai-%E6%A8%A1%E5%9E%8B---%E8%81%8A%E5%A4%A9/createChatCompletion).

<Callout title="Local-first setup">
The API examples use `https://modelsell.com` as a placeholder base URL. Replace it with the live endpoint when the backend is ready.
</Callout>
