---
title: Elements and Voices
description: Manage custom elements, preset elements, custom voices, and preset voices for Kling Omni, O1, and avatar workflows.
---

Elements and voices are shared resources. After creating a custom resource, pass its ID into supported generation tasks.

## Elements

| Action | Method | Path |
| --- | --- | --- |
| Create custom element | `POST` | `/kling/v1/general/advanced-custom-elements` |
| Get custom element | `GET` | `/kling/v1/general/advanced-custom-elements/{id}` |
| List preset elements | `POST` | `/kling/v1/general/advanced-presets-elements` |
| Delete custom element | `POST` | `/kling/v1/general/delete-advanced-elements` |

```bash
curl --location "$KLING_BASE_URL/kling/v1/general/advanced-custom-elements" \
  --header "Content-Type: application/json" \
  --header "Authorization: Bearer $KLING_API_KEY" \
  --data '{
    "name": "brand-character",
    "references": [
      { "type": "image", "url": "https://your-cdn.com/character.png" }
    ]
  }'
```

## Voices

| Action | Method | Path |
| --- | --- | --- |
| Create custom voice | `POST` | `/kling/v1/general/custom-voices` |
| Get custom voice | `GET` | `/kling/v1/general/custom-voices/{id}` |
| List custom voices | `GET` | `/kling/v1/general/custom-voices?pageNum=1&pageSize=30` |
| List preset voices | `GET` | `/kling/v1/general/presets-voices?pageNum=1&pageSize=30` |
| Delete custom voice | `POST` | `/kling/v1/general/delete-voices` |

```bash
curl --location "$KLING_BASE_URL/kling/v1/general/custom-voices" \
  --header "Content-Type: application/json" \
  --header "Authorization: Bearer $KLING_API_KEY" \
  --data '{
    "name": "brand-voice",
    "audio": "https://your-cdn.com/sample.wav"
  }'
```
