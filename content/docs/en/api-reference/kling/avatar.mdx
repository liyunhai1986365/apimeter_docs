---
title: Avatar
description: Use /kling/v1/videos/avatar/image2video for avatar video and /kling/v1/audio/tts for avatar speech.
---

Avatar workflows include avatar image-to-video and text-to-speech.

## Avatar Image To Video

| Method | Path |
| --- | --- |
| `POST` | `/kling/v1/videos/avatar/image2video` |

```bash
curl --location "$KLING_BASE_URL/kling/v1/videos/avatar/image2video" \
  --header "Content-Type: application/json" \
  --header "Authorization: Bearer $KLING_API_KEY" \
  --data '{
    "image": "https://your-cdn.com/avatar.png",
    "prompt": "The avatar looks at the camera and speaks naturally."
  }'
```

Query:

```bash
curl "$KLING_BASE_URL/kling/v1/videos/avatar/image2video/{id}" \
  --header "Authorization: Bearer $KLING_API_KEY"
```

List:

```bash
curl "$KLING_BASE_URL/kling/v1/videos/avatar/image2video?pageNum=1&pageSize=30" \
  --header "Authorization: Bearer $KLING_API_KEY"
```

## Text To Speech

| Method | Path |
| --- | --- |
| `POST` | `/kling/v1/audio/tts` |

```bash
curl --location "$KLING_BASE_URL/kling/v1/audio/tts" \
  --header "Content-Type: application/json" \
  --header "Authorization: Bearer $KLING_API_KEY" \
  --data '{
    "text": "Welcome to Kling avatar.",
    "voice_id": "voice_xxx"
  }'
```
