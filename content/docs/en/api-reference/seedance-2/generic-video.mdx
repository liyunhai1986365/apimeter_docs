`/v1/video/generations` is a platform wrapper, not an official Ark endpoint. Prefer [native content](./modes) for first/last-frame control and explicit media roles.

## Endpoints and mappings

Create with `POST /v1/video/generations` and query with `GET /v1/video/generations/{task_id}`. Do not mix this contract with `/v1/videos`.

| Generic field | Native mapping |
| --- | --- |
| `prompt` | Text content |
| `image` or `images[]` | `image_url` with `reference_image`; not strict first/last frames |
| `metadata.video_url` | `video_url` with `reference_video` |
| `metadata.audio_url` | `audio_url` with `reference_audio`; requires image or video |
| `size` | `resolution`; Fast: 480p/720p; standard additionally 1080p; official standard 4k requires platform confirmation |
| `duration` or `seconds` | Integer output seconds, 4–15; send only one |
| `metadata.ratio` | `ratio`: 21:9, 16:9, 4:3, 1:1, 3:4, 9:16, adaptive |
| `metadata.generate_audio` | `generate_audio` |
| `metadata.watermark` | `watermark` |

Native `duration: -1` support does not confirm generic support. Do not invent metadata mappings for multiple video/audio clips, callbacks, tools, or last-frame return.

## Example

```bash
curl -X POST "$MODELSELL_BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer $MODELSELL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-fast-260128",
    "prompt": "Use image 1 for colors, video 1 for camera movement, and audio 1 as background music",
    "image": "https://example.com/reference-image.jpg",
    "duration": 5,
    "size": "720p",
    "metadata": {
      "ratio": "16:9",
      "video_url": "https://example.com/reference-video.mp4",
      "audio_url": "https://example.com/reference-audio.mp3",
      "generate_audio": true,
      "watermark": false
    }
  }'
```

For text-only input remove image, video and audio. For image reference remove video and audio. Audio cannot be the only media input. Use same-channel `Active` asset URIs where supported; see [Assets](./assets). Official Base64 support is not a promise of generic-wrapper passthrough; prefer URLs.

## Poll and save results

Save `id` or `task_id` from creation and query the same endpoint family:

```bash
curl "$MODELSELL_BASE_URL/v1/video/generations/$TASK_ID" \
  -H "Authorization: Bearer $MODELSELL_API_KEY"
```

```json
{
  "id": "<TASK_ID>",
  "task_id": "<TASK_ID>",
  "object": "video.generation",
  "status": "succeeded",
  "model": "doubao-seedance-2-0-260128",
  "metadata": {"url": "https://example.com/result.mp4"}
}
```

The generic example returns `metadata.url`; native responses use `content.video_url`. Bound polling, handle terminal failures, and download promptly. Official URLs last 24 hours; platform behavior depends on the channel.
