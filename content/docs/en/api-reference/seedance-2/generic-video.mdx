This page describes Seedance 2.0 requests and results through `/v1/video/generations`. For the Seedance official format, see the [unified API overview](./overview).

## Endpoints and mappings

Create with `POST /v1/video/generations` and query with `GET /v1/video/generations/{task_id}`. Do not mix this contract with `/v1/videos`.

| Generic field | Native mapping |
| --- | --- |
| `prompt` | Text content |
| `image` or `images[]` | `image_url` with `reference_image`; not strict first/last frames |
| `metadata.video_url` | `video_url` with `reference_video` |
| `metadata.audio_url` | `audio_url` with `reference_audio`; requires image or video |
| `size` | `resolution`; Fast: 480p/720p; standard also supports 1080p/4k |
| `duration` or `seconds` | Integer output seconds, 4–15; send only one |
| `metadata.ratio` | `ratio`: 21:9, 16:9, 4:3, 1:1, 3:4, 9:16, adaptive |
| `metadata.generate_audio` | `generate_audio` |
| `metadata.watermark` | `watermark` |

Use `duration: -1` for models with automatic duration. `metadata.video_url` and `metadata.audio_url` accept URL arrays. Set `metadata.callback_url`, `metadata.tools` and `metadata.return_last_frame` according to the selected model's specifications.

## Example

```bash
curl -X POST "$APIMETER_BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer $APIMETER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-fast-260128",
    "prompt": "Use image 1 for colors, video 1 for camera movement, and audio 1 as background music",
    "image": "https://example.com/reference-image.jpg",
    "duration": 5,
    "size": "720p",
    "metadata": {
      "ratio": "16:9",
      "video_url": "https://example.com/reference-video.mp4",
      "audio_url": "https://example.com/reference-audio.mp3",
      "generate_audio": true,
      "watermark": false
    }
  }'
```

For text-only input remove image, video and audio. For image reference remove video and audio. Audio cannot be the only media input. You can use `Active` asset URIs that your account can access; see [Assets](./assets). The examples use public URLs for reference media.

## Poll and save results

Save `id` or `task_id` from creation and query the same endpoint family:

```bash
curl "$APIMETER_BASE_URL/v1/video/generations/$TASK_ID" \
  -H "Authorization: Bearer $APIMETER_API_KEY"
```

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "<TASK_ID>",
    "status": "SUCCESS",
    "result_url": "https://example.com/result.mp4"
  }
}
```

Generic queries use `data.status` and `data.result_url`: wait for NOT_START/SUBMITTED/QUEUED/IN_PROGRESS, read results on SUCCESS, and inspect `data.fail_reason` on FAILURE. Creation and query have different shapes. Bound polling, handle terminal failures, and download promptly; video URLs usually expire after 24 hours.
