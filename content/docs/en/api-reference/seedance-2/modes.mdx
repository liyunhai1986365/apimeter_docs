Submit these JSON bodies to `POST /api/v3/contents/generations/tasks`. Replace placeholder URLs with accessible media or an `Active` asset URI that your account can access.

These Seedance 2.0 examples use the ByteDance / Volcengine Ark compatible `content[]` format. Create and query library assets through the [official-format Action endpoint](./assets), then reference their `Result.Id` once active.

## Roles and exclusive modes

| Mode | Image roles | Requirement |
| --- | --- | --- |
| First frame | `first_frame` (official API also allows an omitted role for one image) | One image |
| First and last frames | `first_frame` + `last_frame` | Two images with explicit roles |
| Multimodal reference | `reference_image` | Combine with `reference_video` and/or `reference_audio` |

These three modes are mutually exclusive. Do not mix first/last-frame roles with reference roles. You can describe a reference image as the first or last frame in the prompt, but this is not the strict first/last-frame mode.

Reference limits: 9 images, 3 videos totaling at most 15 seconds, and 3 audio clips totaling at most 15 seconds. Audio requires an image or video; audio-only and text-plus-audio inputs are unsupported.

Refer to “image 1”, “video 1”, and “audio 1” by order within each media type, starting at 1. Do not use asset IDs in prompts. Real-person portraits require the separate authorization flow; see [Assets](./assets).

## Text to video

```json
{
  "model": "doubao-seedance-2-0-260128",
  "content": [
    {
      "type": "text",
      "text": "A dog runs beneath cherry blossoms"
    }
  ],
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5,
  "generate_audio": true,
  "watermark": false
}
```

## First-frame image to video

```json
{
  "model": "doubao-seedance-2-0-260128",
  "content": [
    {
      "type": "text",
      "text": "Orbit the toy robot in the image"
    },
    {
      "type": "image_url",
      "image_url": {
        "url": "https://example.com/reference-image.jpg"
      },
      "role": "first_frame"
    }
  ],
  "resolution": "720p",
  "ratio": "adaptive",
  "duration": 5,
  "generate_audio": true,
  "watermark": false
}
```

```json
{
  "model": "doubao-seedance-2-0-260128",
  "content": [
    {
      "type": "text",
      "text": "Extend video 1 forward in time as the camera moves through the forest toward a lake"
    },
    {
      "type": "video_url",
      "video_url": {
        "url": "https://example.com/reference-video.mp4"
      },
      "role": "reference_video"
    }
  ],
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5,
  "generate_audio": true,
  "watermark": false
}
```

Editing and extension use reference-video roles and prompt instructions, not the Seedance 2.5-only `omni_reference_task_type`. Extension can connect up to 3 clips; output remains within 4–15 seconds and does not necessarily include the entire original clip.
