## Endpoints

| Format | Create | Query |
| --- | --- | --- |
| Ark-native body | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{task_id}` |
| Platform generic body | `POST /v1/video/generations` | `GET /v1/video/generations/{task_id}` |

Prefer native `content[]` for explicit media roles, first/last frames, or multiple references. See [Modes](./modes) and [Generic format](./generic-video). The OpenAI-compatible `/v1/videos` endpoint has its own field contract; do not reuse generic JSON without checking its reference.

Platform assets use `POST /api/assets/upload` and `GET /api/assets/{id}`. These are wrappers, not Ark control-plane CreateAsset/GetAsset APIs.

Direct Ark requests use `https://ark.cn-beijing.volces.com` and an Ark API key. Platform requests use `MODELSELL_BASE_URL` and a platform key; these credentials are not interchangeable. Ark calls the query placeholder `{id}` and this project calls it `{task_id}`; both mean the create response's `id`.

This section covers the operations declared in this project. Official task-list and cancel/delete APIs do not establish equivalent platform routes. Generic and asset-wrapper mappings are based on this project's API definitions; official documentation cannot verify the platform channel implementation.

## Models and native parameters

| Model declared in this project | Official resolutions |
| --- | --- |
| `doubao-seedance-2-0-260128` | `480p`, `720p`, `1080p`, `4k` |
| `doubao-seedance-2-0-fast-260128` | `480p`, `720p` |

Official standard-model 4k support does not establish platform channel support. It uses 10bit H.265/HEVC. Fast does not support 1080p or 4k. The official Mini model `doubao-seedance-2-0-mini-260615` is not yet declared by this project and is not advertised here as available.

| Field | Native contract |
| --- | --- |
| `model`, `content` | Required |
| `resolution` | Default `720p`; model-dependent |
| `ratio` | Default `adaptive`; also `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16` |
| `duration` | Integer 4–15 seconds, or `-1` for automatic selection; examples explicitly use 5 |
| `generate_audio` | Default `true` |
| `watermark` | Default `false` |

Ark also provides last-frame return, callbacks, execution expiry, priority, safety identifiers, and text-only web search. Their full passthrough is not established by this project's schemas; confirm channel support first. Do not invent generic metadata mappings.

Seedance 2.0 does not support draft mode or flex inference. Current official input support for `frames`, `seed`, and `camera_fixed` is limited to older models. `omni_reference_task_type` and selectable MOV output are 2.5 features.

## Native quick start

Set `MODELSELL_BASE_URL` to the platform API root, without `/api/v3`.

```bash
curl -X POST "$MODELSELL_BASE_URL/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $MODELSELL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "content": [{"type":"text","text":"A dog runs beneath cherry blossoms"}],
    "resolution": "720p",
    "ratio": "16:9",
    "duration": 5,
    "generate_audio": true,
    "watermark": false
  }'
```

Save the returned `id` exactly; do not assume a prefix. Poll the matching query endpoint. `queued` and `running` continue; `succeeded` returns `content.video_url`; `failed`, `expired`, and `cancelled` stop polling. Ark only permits cancelling queued tasks and removes cancelled records after 24 hours.

Creation returns a task `id`; do not require a status or video URL at that stage. Official query responses also include fields such as `updated_at`, `duration`, `resolution`, `ratio`, `framespersecond`, `generate_audio`, and `usage.total_tokens`. A successful task's `error` may be `null`. Returned fields do not imply accepted inputs: a returned `seed` does not establish Seedance 2.0 seed input support.

Ark retains queryable tasks for 7 days and video URLs for 24 hours. Download promptly; platform cache behavior may differ. Client polling timeout does not cancel a server task. Resume with the existing ID rather than creating duplicates. See [Python polling](./python-polling).

Multimodal limits are 9 images, 3 videos, and 3 audio clips, with video/audio totals each at most 15 seconds. Audio requires an image or video. First-frame, first/last-frame, and reference modes are mutually exclusive. See [Assets](./assets) for source formats and portrait workflows.
